# On-page SEO — do these on every page

The complete on-page SEO spec for Lanky Services service pages & posts. Technical SEO (sitemaps, robots.txt, Core Web Vitals) is covered separately. Every page should satisfy these.

## 1. Head & metadata
- Title tag — 50–60 chars, primary keyword near the start.
- Meta description — 150–160 chars, keyword + benefit + soft CTA.
- Canonical URL set to prevent duplicates.
- Open Graph — og:title, og:description, og:image (1200×630), og:url, og:type.
- Twitter Card — summary_large_image, title, description, image.
- Language attribute on <html> (lang="en-AU").
- Viewport meta for responsive rendering.
- Favicon + apple-touch-icon.
- Charset meta — <meta charset="utf-8">.

## 2. URL structure
- Short slug — under 60 chars. Primary keyword in slug. Hyphens only, lowercase, no stop words. Logical hierarchy.

## 3. Headings
- Exactly one H1 per page, contains primary keyword.
- Logical H2 → H3 hierarchy, never skip levels.
- H2s use supporting keywords + questions from the cluster.
- No keyword stuffing — write naturally.

## 4. Copy & body
- Primary keyword in the first 100 words. Direct answer to the query in the first paragraph.
- Length matches SERP average. Short paragraphs (1–4 sentences). 8th–10th grade readability.
- Active voice. Bold key phrases sparingly. Bullets & numbered lists where appropriate.

## 5. FAQ section
- 4–8 questions (SEMrush Questions + People Also Ask). Direct answers 2–4 sentences. FAQ schema (JSON-LD).

## 6. Images
- Alt text describes image + keyword where natural. Descriptive filenames with hyphens.
- Compressed (<200 KB where possible). Width/height attributes (prevents CLS). Lazy-load below-fold. Featured/hero image for social sharing.

## 7. Internal links
- 3–5 internal links. Link related service pages. Descriptive anchor text (never "click here"). Contextually placed. Breadcrumbs on every page.

## 8. External links
- 2–3 authoritative sources where relevant (.gov councils, facilities). Open in new tab with rel="noopener".

## 9. Schema markup (JSON-LD in <head>)
- LocalBusiness (most specific subtype), Service on service pages, FAQ wherever an FAQ exists, BreadcrumbList on every page, Organization site-wide, Author/Person for bylines.

## 10. E-E-A-T signals
- Author byline + bio, link to author page, published/updated dates, real stories & numbers, cite sources, About + Contact with real address, phone, hours.

## 11. Accessibility
- Semantic HTML5, ARIA labels, WCAG AA contrast, focus indicators, alt text, descriptive link text, skip-to-content.

## 12. Mobile & responsive
- Responsive layout, touch targets ≥48px, body font ≥16px, no horizontal scroll, no intrusive interstitials.

## 13. Social preview
- OG image 1200×630, Twitter 1200×600, compelling og:description.

## 14. Conversion (service pages)
- Primary CTA above the fold, click-to-call tel:, multiple CTA placements, trust signals (reviews/licence/years), testimonials, service-area coverage, business hours, physical address + embedded map.

## 15. Keyword targeting (Lanky house rule)
- Each page targets a primary keyword in the title + **10 keyword cluster terms** relative to that title, used naturally across H2s, body and the meta keywords tag.
